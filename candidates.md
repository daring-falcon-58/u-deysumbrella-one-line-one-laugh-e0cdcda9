# Candidates — One Line, One Laugh (u-deysumbrella-one-line-one-laugh-e0cdcda9)

Judge criteria in order (competition.yaml / RULES.txt):
1. C1 — Is a funny one-line joke (a non-funny line / caption / stray thought loses to any funny line)
2. C2 — Laugh comes from the line itself: a turn, a surprise, one exact word; not explaining the joke or leaning on a familiar meme
3. C3 — One line, short enough to read in a breath, no setup paragraph, no second line doing the work
4. C4 — Wording is fresh, a joke the reader has not seen a hundred times, plain words that sound like a person talking
5. C5 — Lands on a single read, no footnote, no context, no shared knowledge needed

Scoring: 0–5 per criterion, total /25. Winner = highest total; ties broken by earliest criterion (C1 first). Char counts verified with Python before selection.

Live field at build time: 950 submissions (API, 2026-11-26 ~16:40 WIB; brief's "605" stale).
Blind rounds: R1 17:33 WIB, R2 20:21 WIB, final 23:10 WIB. Prize: $2, 1st place only.
